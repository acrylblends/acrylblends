# ACRYL Blends UX Mockups — Batch 01 (01–10)

Ten distinct app-specific mockups and implementation-oriented design specifications.

## Open

Open `index.html` in a browser, then choose one of the ten app surfaces. The mockups are standalone HTML files and need no install or network access.

## Contents

- `mockups/` — one standalone HTML mockup per category
- `specs/` — one agent handoff per category: intent, screens, data, seed, states, routes and flows

## Category mapping

1. System — System Monitor (`acrylblends.system-monitor`)
2. Application — Productivity Hub (`acrylblends.productivity-hub`)
3. Business — Small CRM (`acrylblends.small-crm`)
4. Developer — Snippet Manager (`acrylblends.snippets`)
5. AI — Prompt Lab (`acrylblends.prompt-lab`)
6. Data — CSV Explorer (`acrylblends.csv-explorer`)
7. Analytics — Web Analytics (`acrylblends.web-analytics`)
8. Cloud — Cloud Costs (`acrylblends.cloud-costs`)
9. DevOps — Deploy Board (`acrylblends.deploy-board`)
10. Networking — Uptime Checker (`acrylblends.uptime`)

## Design rule

Do not normalize these into one layout. Preserve each application's task model: telemetry inspection, personal planning, relationship pipeline, source browsing, controlled prompt experiments, spreadsheet exploration, metric reporting, cloud cost attribution, release operations and endpoint availability.

Each app is intended to become a small Acryl Blends Blueprint with a focused domain plugin and 2–5 real screens. The specs follow `specs/020-blueprints-100-categories/spec.md` and `cloud-brief.md` from the ACRYL Blends framework repository.
