Retrieval systems: a field guide

BY ALEX·6 MIN READ·UPDATED 05 NOV 2026

A useful retrieval system is not a single search technique. It is a set of complementary mechanisms that help a person find the right piece of knowledge at the right moment.

Start with the question

Before choosing an index, clarify what the user is actually trying to retrieve. A person may remember a phrase, a concept, a file name, a decision, or a relationship between two ideas. Each requires a different path into the corpus.

Lexical retrieval is strong when the terms matter. Semantic retrieval is useful when meaning survives a change in vocabulary. A combined approach makes the system more resilient, while reranking can improve the order of the final result set.

“The retrieval model should follow the shape of the information need—not the other way around.”
