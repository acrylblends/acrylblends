# ACRYL Blends · Batch 02 (Categories 11–20)

Ten separate, browser-viewable application mockups for the second ten categories in `specs/020-blueprints-100-categories/tasks.md`.

## Preview

Open `index.html` in a browser or open any file under `mockups/` directly. Every mockup is a standalone HTML page with its own layout, styling and local interactions. Sample data is illustrative. Some sample imagery in Photo Gallery and Moodboard is loaded from Unsplash URLs and therefore requires internet access.

## Contents

- `mockups/` — ten independently designed application surfaces.
- `specs/` — ten agent-oriented implementation handoffs with routes, domain entities, interactions, states, boundaries and acceptance criteria.
- `blueprints-11-20.json` — machine-readable index.
- `INDEX.md` — human-readable batch index.

## Important

These are UX mockups, not finished production software or published Blends. They do not change the ACRYL framework or GitHub repositories. Do not begin Batch 03 until Batch 02 has been reviewed and approved.
