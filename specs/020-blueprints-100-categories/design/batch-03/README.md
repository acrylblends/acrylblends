# ACRYL Blends — Batch 03

**Categories 21–30 · Ten bespoke application mockups**

Open `index.html` to browse the batch. Each preview is a standalone HTML application with its own visual system and product-specific layout.

## Included

- 10 standalone HTML mockups in `mockups/`
- 10 agent-focused implementation specifications in `specs/`
- `blueprints-21-30.json` with category, Blend ID, description, UX, entities, flows and implementation notes
- `INDEX.md` for review and navigation

## Design rule

These are intentionally different interaction models: map canvas, card review, practitioner daybook, finance ledger, matter docket, civic queue/map, personnel qualification matrix, cashier till, customer storefront and editorial calendar. Shared framework conventions do not imply shared application UX.

## Run locally

Open `index.html` in any modern browser. No build step or external dependency is required. Mock data is local to each page; some actions use browser prompts, downloads or local demo state.

## Important boundaries

Healthcare uses sample data only. Finance is a personal budget ledger, not banking or investment advice. Legal content is illustrative, not legal advice. Government public status views must not expose personal data. Military/defense category is restricted to non-operational training administration. POS and e-commerce payments are simulated only. The map is illustrative; the implementation spec calls for OpenStreetMap tiles and attribution for a production map.
