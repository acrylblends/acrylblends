# ACRYL Blends — Batch 04

**Categories 31–40 · Ten bespoke application mockups**

Open `index.html` to browse the ten standalone HTML prototypes. Each concept has its own visual language, layout and core interaction model; the batch deliberately avoids repeating a generic dashboard template.

## Included

- 10 standalone HTML mockups in `mockups/`
- 10 agent-focused implementation specifications in `specs/`
- `blueprints-31-40.json` with purpose, audience, UX direction, data model, flows, constraints and agent brief
- `INDEX.md` for review and navigation

## Design directions

Quote document editor; three-pane ticket inbox; shipment control tower; day-based trip itinerary; restaurant floor plan; image-led property catalogue; construction site notebook; parcel map and field dossier; energy consumption console; telecom asset register.

## Run locally

Open `index.html` in a modern browser, or open any file in `mockups/` directly. No build step or external dependency is required. Actions use local demo state, browser prompts, printing or CSV download.

## Data and safety boundaries

All records are synthetic. Carrier tracking, maps, travel bookings, weather and energy data are illustrative. Tax rates and energy tariff are demo values only. Real-estate artwork is CSS-generated. Telecom identifiers are not provisioned. No external credentials or paid APIs are needed.

## Review gate

This is a prototype package, not ten production implementations. Do not start Batch 05 until Batch 04 has been reviewed and approved.
