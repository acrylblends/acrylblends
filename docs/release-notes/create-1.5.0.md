# create-acrylblends 1.5.0

Asks for [acrylblends 1.5.0](acrylblends-1.5.0.md).

- `npm create acrylblends@latest my-crm -- --from acrylblends.small-crm` makes the blueprint in the ACRYL frame (chat, agents, branches, versions,
  Settings); the Next block names `npm run dev` and `npm run desktop`. `--bare` keeps it plain.
- `--desktop` works with any source (`github:`, an npm package, a folder): it puts that starter in the frame. It was refused before.
- The Next block names README.md only when the app has one (Rifat).
