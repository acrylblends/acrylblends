# create-acrylblends 1.3.0

`npm create acrylblends@latest my-app -- --from <id>` now downloads only the app you asked for.

## What changed

- **One app, one small download.** The public registry publishes each app as its own archive, so `--from` fetches the registry's list and that one archive instead of the whole registry. The largest app today is about 1.5 MB; the whole registry is more than 90 MB.
- **Every archive is checked.** The list names each archive's sha512. If the download does not match, `create` stops and changes nothing.
- **Older registries keep working.** A registry whose list names no archives, or an archive that cannot be downloaded, falls back to reading the whole registry the way 1.2.1 does. So do a folder and a git repository named with `--registry`, except that a folder now copies only the entry.
- **`--registry` takes an https address** of a hosted registry, as well as a folder or a repository.
- **A failed download says which address it could not reach.**

Only `create-acrylblends` changes. `acrylblends` stays at its current version.
