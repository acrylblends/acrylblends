# 0.6.0

An acrylblends app also runs as a desktop app.

```sh
npx acrylblends init my-app --template todo --desktop     # or: npx acrylblends add desktop, in an app you already have
cd my-app && npm install
npm run desktop
```

## New

- **The `desktop` plugin.** `npm run desktop` starts the app's own server in an Electron main process and opens one window on it, with a locked-down renderer (context isolation, no Node in the page, the sandbox), navigation limited
  to the app's own origin, a single-instance lock, and a bounded shutdown that stops the server when the window closes. Electron's user data lives inside the app's own home (`.acrylblends/electron`), never in the user's
  application-data folder. The app's own code never imports `electron`; only `src/plugins/desktop` does. See [the desktop shell](../desktop.md).
- **`init --desktop` and `add desktop`.** A library plugin may now add development dependencies and scripts to the app's `package.json` (`devDependencies`, `scripts` in `plugin.json`; an existing script is never replaced), and a template may
  say where its window opens (`desktopPath`: `/todo` for the todo template).
- **Vendored from ACRYL Desktop** (two small pure files, with a recorded commit and digest like the framework): the isolated user-data folder and the bounded, escalating shutdown.

## Things to know

- Electron is pinned to 44.0.0, the version ACRYL Desktop's source builds on. `npm install` does not download its binary (Electron 44 has no install script); the first `npm run desktop` does, about 100 MB once per machine
  (`ELECTRON_MIRROR` and `ELECTRON_CACHE` apply).
- It runs from source. Packaging a distributable app (dmg, exe, deb) is not part of this release.

## Unchanged

The framework (`import { Acryl } from 'acrylblends'`), the templates, the other plugins, `blend.yaml` and the lock.
