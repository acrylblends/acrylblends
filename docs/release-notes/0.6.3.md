# 0.6.3

The framework package adds the JSX packages and the CSS helper, `save` catches the passwords that were slipping through, and the desktop page is in the docs.

## New

- **`acrylblends/jsx`, `acrylblends/jsx/dom` and `acrylblends/css`**, and their runtimes (`jsx/jsx-runtime`, `jsx/jsx-dev-runtime`, `jsx/streaming`): 91 subpaths now, vendored from ACRYL `60491f81` with a recorded digest.
  Their pages are no longer marked "not yet available", and every code block on them is type-checked against the published package. `jsx-renderer` and `ssg` are still to come.
- **The desktop page** (`getting-started/desktop`) is part of the framework docs: an Acryl app and a Blend app, `acrylblends add desktop`, what it adds, the first-launch Electron download.

## Changed

- **`save` refuses a short literal assigned to a credential-named key** (`password: 'hunter2'`, `const token = '...'`), not only the long key formats it knew. The rule comes from `@webboxes/app-persistence` 0.1.1, which the save plugin
  now depends on. Reads from the environment, placeholders (`<...>`, `${...}`, `xxxx`), values with a space and longer names that only contain the word are still accepted. The scaffolder verification now has a step for both
  directions.
