# 0.7.3

An AI chat starter, and the documentation for streaming an answer from a model.

## New

- **`create-acrylblends --template chat`.** A small chat app: the answer streams token by token over Server-Sent Events from an OpenAI-compatible chat completions API (DeepSeek by default), a client component shows it as it arrives, and a Stop button aborts the request, and the server's own request to the model with it. The base URL and model come from `DEEPSEEK_BASE_URL` and `DEEPSEEK_MODEL`; the key comes only from the environment variable `DEEPSEEK_API_KEY` and is never written to a file, a response or a log. Conversation history is stored with `node:sqlite` behind a small `chatStore`. The tests use a mock model and never the network, and the app takes the desktop shell with `npx acrylblends add desktop`.
- **Docs.** The streaming helper page gains "Cancelling work when the client leaves" (what `c.req.raw.signal` and `stream.onAbort` each report, and the already-aborted pitfall), a server example that reads an OpenAI-compatible streaming upstream, and a tested snippet that reads a POST event stream in the browser. The client components guide gains a form and its state in an island.

## Things to know

- `create-acrylblends` 0.2.3 depends on `acrylblends` `^0.7.3`; the framework itself is unchanged from 0.7.2.
- Anyone who can reach a chat app can spend your model key: put it behind a login or on a private network before it is public.
