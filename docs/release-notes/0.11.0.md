# 0.11.0

## Added

- **WebSocket upgrades on the router (spec 047 T009).** A plugin takes upgrades with `ctx.nodeServer.upgrades()` (standalone server) or `ctx.routerHttp.upgrades()` with `ctx.routerHttp.mount(prefix, { upgrade: [paths] })` (the ACRYL Host's web server): the ported `upgradeWebSocket` on an ordinary route, with ordinary middleware in front of it. The origin, loopback and host checks run before the upgrade, and a refusal is a plain HTTP status with `Connection: close`. A non-WebSocket `Upgrade` request is answered 400.
- **The plugin owns its sockets.** When the plugin unloads, every socket its routes accepted is closed with 1001 within `websocket.grace`, the handler sees `close` exactly once, and other plugins' sockets are untouched. Stopping the server closes everything. `ctx.nodeServer.sockets` / `ctx.routerHttp.sockets` count what is open.
- **Limits.** Text frames only with `{ textOnly: true }`, `websocket.maxPayload` (default 1 MiB; a bigger frame closes with 1009), no per-message compression, `bufferedAmount` on the socket for back-pressure, application close codes (1013, 4404, ...), and a ping every `websocket.heartbeat` ms (default 30 000) that ends a peer that stops answering.
- **`testWebSocket`** (from `acrylblends/node-server`): runs an upgrade route and its middleware in process, no network.
- `acrylblends/node-server` also exports `UpgradeHub` (needs the optional `ws` peer) for apps without Cordis.
- **`acryl brief` prints the app's address** (text and `--json`), so an agent can curl a route it just added without reading `.acryl/door.json`.

## Fixed

- The app guide (`AGENTS.md`) names the import a plugin installed into the running app uses: `import { Acryl } from 'acrylblends'`. A plugin that wrote a relative path to the router failed its first install in the real-agent run.

## Things to know

- `ws` is a new optional peer of `acrylblends`; install it to use upgrades. `acryl-node-server` no longer lists `acryl-router-http` as a requirement, and `acryl-router-http` requires `acryl-node-server` (it uses the upgrade hub).
- `create-acrylblends` 0.4.1 depends on `acrylblends` `^0.11.0`.
