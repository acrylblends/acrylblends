# 0.9.0

The framework has one home: this repository. Its source, its tests and its history moved here from ACRYL, and the package is built and published from here alone, with no copy step.

## New

- **The Cordis forms are subpaths of `acrylblends`.** `acrylblends/cordis/router`, `cordis/router-http`, `cordis/state` (and `cordis/state/react`), `cordis/inspect`, `cordis/node-server`, `cordis/db`, `cordis/db-sqlite`, `cordis/kv`, `cordis/kv-json`, `cordis/kv-db` and `cordis/door` are the framework plugins as modules of the package, for a project that runs Cordis and wants the packages instead of a copy of their source. Their peers are optional: `@deepseek-ai/cordis` (^4.0.2), `@deepseek-ai/schemastery`, `react` (for `cordis/state/react`) and `vitest` (for the suites). An app that imports only the plain subpaths never loads any of them; a test checks that no plain entry reaches one.
- **One `Acryl`.** `new Acryl()` from `acrylblends` is the class `acrylblends/cordis/router` mounts: one chunk defines it, and a test asserts the identity.
- **More subpaths** (126 in all): `acrylblends/door/host`, `door/protocol` and `door/page` (browser code) for tools built on the door, and `acrylblends/db/conformance` and `kv/conformance`, the suites a provider of a port passes (they run on `vitest`).
- **The source is here with its history.** `plugins/acryl-*` (the router, router-http, node server, state, inspect, db, db-sqlite, kv, kv-json, kv-db, door) and `packages/framework` (the build of the package) came over with the commits that made them, and `docs/framework` is the framework's own text. Their test suites run natively here, on Linux, macOS and Windows with Node 22 and 24 (`.github/workflows/ci.yml`).
- `acrylblends init` and `add` rewrite the imports of a library plugin to relative paths when they copy it into an app, from each plugin's `entries` table; the sync, vendor and verify scripts and their provenance records are gone.

## Things to know

- `acrylblends add kv --suite` (and `db`) installs `vitest` 3.2.4. npm 10, the npm of Node 22, crashes ("Cannot read properties of null (reading 'edgesOut')") on the dependency tree of vitest 4 and 5; the suites use only `describe`, `it` and `expect`, which are the same in all of them, and an app on a newer npm may raise the version.
- `create-acrylblends` 0.3.2 depends on `acrylblends` `^0.9.0`.
