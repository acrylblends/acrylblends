# 1.2.1

`create-acrylblends` 1.2.1 (`acrylblends` stays at 1.2.0).

## Fixed

- **`create --from` works on a registry of any size.** 1.1.0 and 1.2.0 held the whole registry to the limits of one template (5000 files, 50 MB),
  so once the public registry grew past 5000 files every `npm create acrylblends -- --from <id>` failed with "the template has more than 5000
  files". A registry is now read with its own bound (200,000 files, 2 GB, only against a runaway download), and the starter taken from it is still
  held to the template's limits. This holds for the public registry, a `github:` registry and a local `--registry` folder.
