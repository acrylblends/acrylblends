# 0.9.2

## Added

- **Stop cancels the app's own agent.** `agent.run(question, { signal })` ends the run `{ status: 'cancelled' }` as soon as the signal aborts: the model call or tool in flight is dropped, the trace records an interrupted tool call as `cancelled`, and a task record, when the app records tasks, is marked failed. The model and tools receive the signal (`ModelInput.signal`, `Tool.run(input, { signal })`) to stop their own work. The agent panel's Stop button uses it.
- **A secrets scan in `pnpm run check`.** `verify:secrets` runs the scan `save` uses over the framework docs, the templates and the packages' source, so an example with a literal credential cannot ship.

## Fixed

- The npm page of `acrylblends` shows the logo from the site (`https://acrylblends.github.io/logo/mark.png`).
- Flaky gates: the node server's memory-leak tests collect until the request objects are gone, and the probes take their ports from a helper that never returns a port `fetch` refuses.

## Things to know

- `create-acrylblends` 0.3.4 depends on `acrylblends` `^0.9.2`.
