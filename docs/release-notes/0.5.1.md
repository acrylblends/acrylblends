# 0.5.1

The npm page of `acrylblends` is no longer empty. The package now carries a README at its root: a getting-started page for the framework (install, a first API, middleware, validation, the typed client,
testing, serving on Node.js, what is in the package, upgrading from 0.4, the `acrylblends` command) with links to the documentation, the repositories and the sites. ACRYL writes it and checks every example in it against
the packed package; here it is synced like the other vendored files, with a recorded commit and digest, and `pnpm run verify:framework` fails when the copy differs.

`create-acrylblends` 0.1.1 has a short README too: the one command, the templates, the options and the links.

Nothing else changes: the package code is 0.5.0's, and the docs and plugins are re-synced from ACRYL main.
