# 0.7.1

A security update for the desktop window, a fix for a warning on Windows, and a better first hour for an app built with a coding agent.

## Fixed

- **Electron 44.9.3** (was 44.0.0, which has published advisories) in both desktop plugins. `acrylblends add desktop` adds it; an app that already has the shell can set `"electron": "44.9.3"` in its `package.json` and run `npm install`.
- **No more Node `DEP0190` warning on Windows.** `acrylblends init --install` and `create-acrylblends` start the package manager without a shell (npm runs through `node` and `npm-cli.js`; other managers through `cmd.exe /d /s /c`), and a test keeps `shell` out of the spawn call.

## Better for coding agents

- A `nodejs` app's `AGENTS.md` now says how to run the app as a desktop window (`npx acrylblends add desktop`, `npm install`, `npm run desktop`) and that `testClient` only types routes chained on `new Acryl()`.
- The framework docs gain **Forms, sessions and a database** (`guides/forms-and-sessions.md`): `node:sqlite`, scrypt passwords, a cookie session, validated HTML forms, a JSON API that shares the rules, and tests for every route. Fixes to the signed-cookie example (it used `await` in a non-async handler), the client components page (broken image URLs), and the validation page (an invalid form answers 400).

## Things to know

- `create-acrylblends` 0.2.1 depends on `acrylblends` `^0.7.1`.
