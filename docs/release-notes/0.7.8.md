# 0.7.8

An app that carries its own self-knowledge, with one plugin folder; and `readSSE` for the browser.

## New

- **One plugin folder, `plugins/`.** In an app made by `acrylblends init`, every plugin lives in `plugins/<name>/` at the root of the app: the library plugins `acrylblends add` copies, and the plugins you or an agent write. `src/plugins/` and `extensions/` are gone. `plugins/library.json` lists the library copies, so the extensions plugin installs everything else in the folder and never mounts a copy twice. `acrylblends check-deps` scans `plugins/`. An app made before 0.7.8 keeps working for this release: its `src/plugins/` and `extensions/` are still read, with a warning that names the move (`git mv src/plugins plugins`; see `docs/framework/agents/index.md`).
- **Self-knowledge in every new app.** `AGENTS.md` and `CLAUDE.md` carry the same text, and one skill, `app-guide`, is written to `.claude/skills/app-guide/SKILL.md` and `.agents/skills/app-guide/SKILL.md`: where to read first, the one plugin folder, the defaults, and what "done" means. Both name the defaults and how each is swapped (the database, the key-value store, the server, the window, browser code): every choice is a plugin behind a port, and the default is only a fallback. `create-acrylblends` apps and `acrylblends init` apps both get them.
- **`.acryl/` is ignored by git** in every template, for the folder an agent door keeps its state in.
- **`acrylblends/read-sse`** (109 subpaths): `readSSE(response)` reads a server-sent event stream as an async iterable of `{ event, data, id, retry }`, in the browser and on Node. The `clientModules` runtime serves it.
- **`acryl-kv-json` writes are grouped**: concurrent writes share one file write, with the same crash guarantees.

## Things to know

- `create-acrylblends` 0.2.8 depends on `acrylblends` `^0.7.8`.
- Postgres is not part of this package. It is an optional provider you add when an app needs a server database.
- The text of the door command (`.acryl/bin/acryl`) is in the `acrylblends init` apps' guide only; the plain `create-acrylblends` apps do not mention it until they have one.
