# 0.5.0

`acrylblends` is now the framework. `import { Acryl } from 'acrylblends'` gives you a small web framework on Web Standards, with every middleware and helper at its own subpath, and a new
starter, `npm create acrylblends@latest`, creates a project for it. The Blend tooling (`acrylblends init`, `add`, `plugins`) is unchanged.

## Breaking changes

1. **The package root is the framework.** Before, `import ... from 'acrylblends'` gave the scaffolder's functions (`runCli`, `init`, `copyPlugin`, ...). They moved to
   `acrylblends/cli`. The `acrylblends` command is the same.
2. **The application class is `Acryl`, the request type is `AcrylRequest`.** In Blend apps and plugins, `App` and `AppRequest` still work and are marked deprecated;
   they are removed in the next release. See [Migration from 0.4](../framework/cordis/migration-from-0-4.md).
3. **Live plugins import the framework by the docs' names.** A plugin the agent writes while the app runs imports `Acryl` from `acrylblends` and each middleware or helper from
   `acrylblends/<subpath>`; the old `acryl-router` names keep working.

## New

- **The framework as a package.** `acrylblends` exports 74 subpaths: the root (`Acryl`, `Context`, types), the 25 middleware (`acrylblends/cors`, `acrylblends/jwt`, ...), the helpers
  (`cookie`, `streaming`, `html`, `factory`, `testing`, `validator`, `client`, `ws`, `conninfo`, ...), the five routers, `utils/*`, and the Node.js adapter at `acrylblends/node-server`
  (`serve`, `serveStatic`, `getConnInfo`). Two subpaths are ours: `acrylblends/schema-validator` (`schemaValidator`, for any Standard Schema) and `acrylblends/loopback-only`.
  It has no dependencies, is ESM, and its types stand without the DOM library. The source is ACRYL's, vendored from commit `618185b4` and checked against a recorded digest.
- **`create-acrylblends`:** `npm create acrylblends@latest my-app` asks for a template (`nodejs`, `bun` (experimental) or `acryl-app`, the agent Blend) or takes `--template`, `--install`,
  `--pm` and `-y`. Every template contains `AGENTS.md`, `CLAUDE.md` and a copy of the framework docs.
- **New framework documentation,** 87 pages in `docs/framework`, organized as getting started, API, concepts, guides, helpers and middleware, plus the Cordis pages and an agents page. Pages for
  parts that are not ported yet say "not yet available". Node.js is the verified runtime; Bun is experimental.
- **The docs are tested.** Every code block that imports the package is extracted and type-checked against the real package (`docs/test/framework-code.test.ts`).
- **The agent template's tsconfig** maps the docs' names to the vendored framework, so what the docs write type-checks in the app.

## Unchanged

The templates `blank`, `todo` and `agent`, the plugin library, `blend.yaml` and the lock, the registries, Node 22.19 or newer for the CLI.
