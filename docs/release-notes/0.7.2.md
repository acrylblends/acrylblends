# 0.7.2

Client components without a bundler, a safer default for `serve()`, a production-ready starter, and the framework brought up to date.

## New

- **Client components with no bundler.** `clientModules({ root, compiled })` and `buildClientModules({ root, outDir })` from `acrylblends/node-server` serve a folder of `.tsx` and `.ts` client modules to the browser, compiled when the browser asks with the app's own `typescript`. `acrylblends build-client [root] [outDir]` (defaults `src/client` and `dist/client`) compiles them once for production; with `NODE_ENV=production` only the built folder is served. Guide: `docs/framework/guides/client-modules.md`.
- **`create-acrylblends --template notes`.** A small full-stack starter: sign up and log in (scrypt, cookie session), notes in SQLite through `node:sqlite`, validated forms, search, a JSON API with a typed test client, csrf on, a test for every route. Its live character counter is a client component. It takes the desktop shell with `npx acrylblends add desktop`.
- **A Deploy page** (`getting-started/deploy.md`): environment variables, `npm ci --omit=dev`, a systemd unit, Caddy and nginx snippets, the SQLite file and backups.
- **`schemaValidator` takes the full Standard Schema v1 shape** (`version`, `vendor`, `validate`), and `testClient` takes default headers as its fourth argument. The forms and sessions guide shows validating a real HTML form.

## Changed

- **`serve()` binds `127.0.0.1` unless `hostname` is given** (it used to listen on every interface); `0.0.0.0` or `::` opts in. The default HTTP/1 call returns `http.Server`, so `server.closeIdleConnections()` type-checks.
- **The `nodejs` and `notes` templates are ready for production:** `HOST` and `PORT` from the environment, a graceful stop on SIGTERM and SIGINT (server and database closed, exit within 10 seconds), and `typescript` as a runtime dependency (the `.tsx` hook compiles with it at start; before, `npm ci --omit=dev` could not start an app with `.tsx` pages). The Blend templates (`blank`, `todo`, `agent`) get the same dependency. The `notes` template marks the session cookie `Secure` behind HTTPS or a trusted proxy (`TRUST_PROXY=1`), takes `PUBLIC_ORIGIN` for csrf behind a proxy, and answers errors with a plain 500.

## Things to know

- An app made with an earlier template that listened on all interfaces by accident now listens on `127.0.0.1` after updating `acrylblends`; set `HOST=0.0.0.0` (or pass `hostname`) where you meant to expose it.
- `create-acrylblends` 0.2.2 depends on `acrylblends` `^0.7.2`.
