# 0.4.1

A coding agent (Claude Code, Codex, OpenCode, Copilot) working inside a generated app now finds the framework's API in the folder it is in. Nothing breaks.

## New

- **`docs/framework/` is in every generated app.** `acrylblends init` copies the framework's docs (routing, request, context, validation, helpers, middleware, plugin
  lifecycle, the node server, and the migration from 0.3) into the app, for all three templates. They are ACRYL's own pages, checked against their digest in this repository.
  The cost is 15 files, about 63 KB of text.
- **`AGENTS.md` and `CLAUDE.md` in every generated app.** `AGENTS.md` says where the API is (`docs/framework/README.md`), how to build a feature (an `App` mounted with
  `ctx.router.route`, a plugin registered in `src/app.ts` and `blend.yaml`, a state cell), the things that surprise people (strict trailing slashes, the validation error
  shape, the JSON `Content-Type`), and what must pass before a task is done. `CLAUDE.md` is `@AGENTS.md`. Each template adds a short section about itself.
- **A manual gate for this:** `scripts/verify-coding-agent.mjs` generates an app, starts a headless coding agent in it with a one-line task and checks that the app's tests and
  type-check pass afterwards, using only what is in the folder.

## Changed

- **Framework docs, re-synced from ACRYL `64e7c9d2`:** a one-page `api-summary.md`; the trailing-slash rule with a measured table (a page mounted at `/x` answers `/x`, and
  `trimTrailingSlash()` redirects `/x/` for GET and HEAD); the exact validation failure shape (`{ error: 'invalid <target>', issues: [{ message, path }] }`); the JSON
  `Content-Type` trap with a `jsonOnly` recipe that answers 415; the `todo` template now uses `trimTrailingSlash()` and its tests cover it.
- **The inspector lists each route as its own entry** instead of one label per mount, so a large app's report stays readable.

- **A live plugin's `check` receives the plugin's own context.** `ctx.router` reads the same in `apply` and in `check`; the agent's generated plugins and the model prompt no
  longer use `ctx.get('router')!` in `check`.
- **The templates' README and manifest comments are current:** the `App` mount, strict trailing slashes, where the router API is documented, and that `npm run dev` restarts the app when a file changes.
