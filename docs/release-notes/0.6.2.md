# 0.6.2

The framework package ships the rest of what its docs described as "not yet available" in the first group: the presets, the dev helper, mount, cache and proxy.

## New

- **Six more subpaths, 80 in all** (81 export entries with `./cli`): `acrylblends/tiny` and `acrylblends/quick` (the same `Acryl` with the smallest router and with the registration-fast router), `acrylblends/dev`, `acrylblends/mount`, `acrylblends/cache` and
  `acrylblends/proxy`. They are ACRYL's, vendored from commit `0174cb01` with the rest of the package and checked against a recorded digest.
- **Their pages are no longer marked "not yet available"**, and every code block on them is type-checked against the published package like the rest of the docs.
- The package README (the npm page) lists the new subpaths and greets with `'Acryl!'` in its examples, as the starter does.

## Still not available

`acrylblends/jsx` and its subpaths, `css`, `jsx-renderer` and `ssg`, and the adapters of the runtimes other than Node.js: their pages say so at the top.
