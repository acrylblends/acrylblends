# 0.9.1

A fix to 0.9.0: apps made by the installed command line did not start.

## Fixed

- **`acrylblends init`, `add` and `create-acrylblends` made apps whose framework plugins could not find each other** (`Cannot find package 'acryl-router'` ...). 0.9.0 rewrote the imports between the plugins at copy time only when the plugin's source folder in the package had a `package.json`, which the published package leaves out, so it worked from the repository and not from the installed package. The rewrite now goes by the `entries` table of each plugin's `plugin.json`, in both. Use 0.9.1; 0.9.0 is deprecated.
- **A gate that runs the installed command line.** `pnpm run verify:packed` packs `acrylblends` and `create-acrylblends`, installs only those two tarballs into an empty folder, makes an app of every template with the installed commands, and runs the new app's tests and type-check. It fails on 0.9.0.

## Things to know

- `create-acrylblends` 0.3.3 depends on `acrylblends` `^0.9.1`. An app made with 0.9.0 can be repaired by creating it again; its own code is unaffected.
