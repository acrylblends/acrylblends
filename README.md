# ACRYL Blends framework: moved

The ACRYL Blends framework moved into the ACRYL monorepo: https://github.com/acryldev/acryl/tree/main/framework

Its packages are now `@acryldev/blends` and `@acryldev/create-blends` (the short names `acrylblends` and `create-acrylblends` still work).
